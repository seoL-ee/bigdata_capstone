# PawInHand evidence audit 결과 보고서

## 요약

PawInHand 3개월 raw JSON 23개에서 22,511 records를 확인했다. `notice_id` 결측과 중복은 각각 0건이다. 이번 작업은 기존 comment screening을 정리하고 기관별 집중도를 추가한 evidence audit이며 새 ML/NLP/LLM 모델은 포함하지 않는다.

- `personality.comment`: 381/22,511건 (**1.69%**)
- `personality.tags`: 576/22,511건 (2.56%)
- `personality.gauges` 중 하나 이상 값이 존재하는 record: **823건 (3.65%)**; 활동성·사회성·친화도는 각각 815건, 건강상태는 812건
- `detail_status_raw == present`: 843건 (3.74%)
- nested detail 값을 whitespace와 빈 map까지 제외해 판정한 `detail_present_clean`: **841건 (3.74%)**

기존 저장 상태값 기준 present는 843건이었으나, whitespace-only/실질 값이 비어 있는 2건을 제외하면 실제 상세정보 존재 record는 841건이었다. 해당 두 record는 경북-상주-2026-00277 및 경북-상주-2026-00276이다. raw 상태값은 보존하고 분석에는 clean field를 사용한다.

## Comment keyword screening

아래 수치는 `personality.comment` 381건에서 정규식 keyword hit를 탐색한 결과다. 의미가 올바른 행동 관찰인지 확인한 값이나 실제 feature coverage가 아니다.

| screening feature | keyword hit | comment 비율 | comment-only vs tags 및 special_mark |
|---|---:|---:|---:|
| 사람 상호작용 관련 | 276 | 72.44% | 29 |
| 활동성/에너지 | 151 | 39.63% | 36 |
| 교육/훈련 필요 | 56 | 14.70% | 46 |
| 개와의 관계 | 48 | 12.60% | 26 |
| 특수 돌봄 | 30 | 7.87% | 26 |
| 혼자 있는 시간 | 24 | 6.30% | 24 |

따라서 comment가 있는 일부 개체에서는 tags 또는 `special_mark`와 겹치지 않는 추가 keyword evidence candidate가 보인다. 특히 교육/훈련, 혼자 있는 시간, 특수 돌봄, 활동성, 개와의 관계에서 추가 hit가 탐색됐다. 이는 comment가 전체 profile의 주 source라는 뜻이 아니며 수동 검증된 행동 evidence도 아니다.

## 반복적으로 탐색된 표현

comment에서 사람 친화력 관련 표현 105건, 좋아하는 것 87건, 에너지/활동성 65건, 타 동물 친화력 60건, 교육/훈련 56건, 싫어하는 것 55건, 이상적인 가정 54건이 탐색됐다. 일부 comment는 semi-structured profile과 비슷한 구성을 보이지만, 전체 comment가 같은 template을 따르지는 않는다. 기관 안내, 연락처, 홍보 문구와 일반 자유서술도 섞여 있다.

## 보호센터별 상세 comment 편중

raw `shelter_name` 기준 결과다. structured comment candidate는 `사람 친화력`, `타 동물 친화력`, `에너지 레벨`, `좋아하는 것`, `싫어하는 것`, `이상적인 가정` 중 하나 이상의 표현이 있는 comment로 정의했다. 모두 keyword screening이며 표준 template 판정은 아니다.

- 전체 보호센터: **245개**
- comment 1건 이상 보유: **19개**; 5건 이상: **15개**; 10건 이상: **12개**
- comment 381건 중 상위 1개 보호센터: **19.16%** (73건)
- 상위 5개: **56.96%** (217건); 상위 10개: **83.99%** (320건)
- 구조화 comment candidate: **55건**, 모두 서울시립동물복지지원센터 동대문(28건)과 마포(27건)에서 탐색됐다.

Comment는 소수 보호센터에 집중되어 있고, 구조화 후보는 두 센터에만 나타났다. 따라서 comment의 형식은 PawInHand 전반의 공통 기록 관행이라기보다 일부 기관의 기록 방식 영향을 받을 가능성이 있다. 이 집계는 기관별 기록 편향 가능성을 보여줄 뿐 실제 작성자나 프로그램을 확정하지 않는다.

## 현재 분석 질문에 대한 답

### A. `personality.comment`가 추가 정보를 주는가?

**제한적으로 Yes.** 전체 coverage는 1.69%로 매우 낮지만, comment 보유 record에서 tags 또는 `special_mark`에 없는 추가 keyword evidence candidate가 탐색됐다. comment는 일부 개체의 richer evidence 후보이며 전체 동물 profile을 채우는 주요 source는 아니다.

### B. comment의 구조가 반복 가능한가?

**일부 comment에서는 Yes, 전체적으로는 No.** 특정 항목 표현이 반복되지만 자유서술과 기관 안내 등도 섞여 있어 모든 comment를 동일 구조의 성격 프로필로 볼 수 없다.

### C. 특정 기관에 편중되어 있는가?

**일부 보호센터 집중이 확인된다.** 상위 5개가 comment의 56.96%, 상위 10개가 83.99%를 차지하며 구조화 후보 55건은 두 기관에 집중됐다. 기관의 기록 방식이 결과에 영향을 줄 가능성을 고려해야 한다.

### D. comment를 성격 ground truth로 사용할 수 있는가?

**No.** 작성자, 기관 간 평가 기준, 관찰 시점·기간·상황, 가정환경에서의 행동 지속성 및 평가자 간 reliability가 확인되지 않는다. comment는 contextual behavioral evidence 후보로만 취급하며 동물의 고정된 true personality label로 사용하지 않는다.

### E. 현재 데이터만으로 추천 시스템을 객관적으로 평가할 수 있는가?

**아직 No.** user-animal interaction, 사용자별 relevance, 찜·문의·방문 기록, 입양 후 만족도 및 장기 입양 유지 결과가 연결되어 있지 않다. extraction screening과 recommendation ranking 평가는 별개이며 추천 evaluation은 unresolved issue로 남는다.

## 한계와 검토 상태

- keyword hit와 structured comment candidate는 탐색 결과이며 실제 행동 evidence coverage, 정확한 성격정보, ground truth 또는 검증된 적합성을 나타내지 않는다.
- `comment_review_sample.csv`에 수동 검토용 120건과 manual field를 준비했으나 manual validation은 아직 수행하지 않았다.
- 기존 CSV와 raw JSON을 대조해 전체 record, comment count, 종별·상태별 comment, keyword screening 요약을 확인했다. clean detail 판정과 shelter 집계는 raw JSON에서 재계산했다.
